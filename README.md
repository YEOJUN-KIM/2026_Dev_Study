## 학습 자료 정리 방식

- 학습 순서는 `01_`, `02_`처럼 번호로 확인합니다.
- 학습 단계마다 폴더를 만들기보다, 한 분야 안에서 노트북 파일을 바로 열 수 있게 구성합니다.
- `data`, `models`, `common`, `reference`, `scripts`처럼 역할이 분명한 자료만 별도 폴더로 구분합니다.
- 이미 반복해서 배운 준비 코드는 한 셀에 묶고, 새로 배우는 기능은 설명과 함께 단계별로 정리합니다.
