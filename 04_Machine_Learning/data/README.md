| 파일 | 사용 노트 |
| --- | --- |
| `ecommerce_customers_noisy.csv` | 데이터 전처리 |
| `ecommerce_customers_clean.csv` | 특성 엔지니어링 |
| `perch_dimensions.csv` | 다중·다항 회귀 |
| `housing_price_1000.csv` | 회귀 모델 비교·튜닝 |
| `08_wine.csv` | 분류 기초 |
| `08_wine_exe.csv` | 앙상블·성능평가 |
