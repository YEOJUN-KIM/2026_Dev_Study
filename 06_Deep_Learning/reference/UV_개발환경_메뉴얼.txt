	 #2. 작업디렉토리 생성(이 폴더 안에서 실제 작업할 폴더들을 만들어서 사용)

	 #5. 텐서플로우 사용을 위한 [가상환경 생성하기]
	   - 작업할 디렉토리로 이동 후 진행해야함
	   - 가상환경 생성
	     >uv venv .venv --python 3.10
		
		
	 #6.GPU 드라이브 사용을 위해 가상환경 활성화 파일(activate) 설정 수정
	   ** 이 부분은 작업디렉토리 마다 가상환경 생성시 1회 수행합니다.(GPU를 사용하는 경우만)
	   - 꼭~~!! 수행할 작업디렉토리 폴더로 이동한 후 수행해야 합니다.
	   - 꼭~~!! 관리자 권한으로 터미널을 열어서 해야합니다.
	   
	   >cat << 'EOF' >> .venv/bin/activate

# TensorFlow CUDA Library Paths
if [ -d "$VIRTUAL_ENV/lib/python3.10/site-packages/nvidia" ]; then
    NV_LIBS=$(find "$VIRTUAL_ENV/lib/python3.10/site-packages/nvidia" -type d -name lib | paste -sd ":" -)
    export LD_LIBRARY_PATH="$NV_LIBS:$LD_LIBRARY_PATH"

    # 모델 학습 시 XLA(libdevice) 컴파일러 경로 누락 경고 방지
    export XLA_FLAGS="--xla_gpu_cuda_data_dir=$VIRTUAL_ENV/lib/python3.10/site-packages/nvidia/cuda_nvcc"
fi
EOF

	     - .venv 폴더 삭제 명령

	- 우분투 서버에서 아래 진행되면
	  * 우분투 ssh 삭제
	    >sudo apt purge openssh-server -y
		
	  * ssh 캐시 메모리 완전히 정리
	    >sudo apt autoremove -y
	  
	  * ssh 설치
	    >sudo apt install openssh-server -y
		
  	  * ssh 서비스 재시작하기
	  >sudo service ssh restart
	  
	  * 포트(port)를 수정하고자 하는 경우만 아래 진행
	    >sudo nano /etc/ssh/sshd_config
		  -> #Port 22 -> 앞의 주석(#)을 지우고 Port 2222로 변경
		  -> #PasswordAuthentication yes -> 앞의 주석(#)을 지우고 PasswordAuthentication yes로 설정
		  
	  * 서비스 시작
	    >sudo service ssh start
		
	  * 파일질라 접속 테스트
	    - ip : 127.0.0.1
		- name : service
		- 암호  : servicepw
		- 포트  : 22
