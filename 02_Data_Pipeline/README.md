# Data Pipeline

데이터를 **읽고 → 정제하고 → 집계/시각화하고 → 웹에서 수집하고 → 반복 작업을 자동화하는 흐름**을 중심으로 정리했습니다.
기존 강의의 `chapter` 번호 대신 실제 학습 내용이 바로 보이도록 주제별로 재배치했습니다.

## 학습 흐름

```text
NumPy / Pandas 기초
        ↓
외부 데이터 연동 및 전처리
        ↓
집계 및 시각화
        ↓
HTML 구조 이해와 웹 스크래핑
        ↓
Selenium 동적 데이터 수집
        ↓
예외처리 · 저장 · 자동화 · 리팩터링
        ↓
Machine Learning (추후 보강)
```

## 구성

- `01_foundations` — NumPy, Pandas 기본
- `02_data_processing` — 파일 연동, 정제, 집계
- `03_visualization` — 데이터 시각화
- `04_web_data` — HTML 구조, 정적/동적 스크래핑
- `05_automation` — 안정적 수집, 자동화, 리팩터링
- `06_machine_learning` — 추후 회귀/모델 학습 자료 추가 예정
- `data` — 실습에 사용한 대표 데이터

생성 시점만 다른 중복 CSV, 설치 안내 이미지, 백업 requirements, 중복 웹 구조 노트 등은 통합본에서 제외했습니다.
